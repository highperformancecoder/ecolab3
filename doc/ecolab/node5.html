Structure of the Ecolab Simulation System

Ecolab is built on three main class libraries: the arrays class, which implements dynamic arrays, the globals class, which define the global state variables of the model and tcl++ which provides bindings to the TCL scripting language. Each of these class libraries will be described in subsequent sections.

Further modules of the system include analysis and Xecolab, which provides a number of generic instruments for observing the Ecolab system, and aux, which contains code for implementing a client/server version of Ecolab, with the instruments running in the client system, and the model running on the server, and code for implementing checkpoint/restart. This minimises the amount of traffic between a compute server and a client.

The Ecolab model itself is defined in the model specific file ecolab.cc. To define another model, replace this file by another one with similar functions. An example of this is newman.cc. See §6 for more details.

The whole computation is constructed from a TCL[2] script. Example scripts include ecolab.tcl, pred-prey.tcl, lifetime.tcl and console.tcl/engine.tcl for a sample client/server system.
