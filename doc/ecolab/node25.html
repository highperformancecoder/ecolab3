get

Syntax:

get variable

where variable is the name of an ecolab state variable from the list: nsp, tstep, density, tags, species, repro_rate, mutation, interaction(diag), interaction(val), interaction(row), interaction(col). This command returns the value of the state variable a TCL list, which can be further processed by TCL programs.
