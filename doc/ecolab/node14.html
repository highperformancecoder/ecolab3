Connect_plot

This command takes no arguments, and displays the connectivity of the interaction matrix for each cell. The ecologies are ordered within each cell to show up the independent subecologies, and if the palette variable (§12.3) has been defined, each of the independent subecology is coloured differently.

There are two buttons which allow the user to zoom in and out by a scale factor of two. One can also zoom in by clicking with the right mouse button at the location you wish to zoom in on. The plot can also be dragged with the left mouse button to change the view.
