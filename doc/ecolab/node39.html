Indexing and Gather/Scatter

The expression a[10] is meant to be an lvalue (i.e. can be assigned to) that refers to the tenth element of a. When the values of a are internally stored in a contiguous memory location, this is easy, with the method returning a reference. However, if the data is stored in a distributed fashion, references are not possible, and a function will need to be called to extract the value, or alternatively alter the value, depending on the context. This achieved by a helper class par_addr_double. This can either be type cast to a double, in which case the function returning the value of a[i] is called, alternatively, it can be assigned to, in which case the alteration function is called. If more than one array variable refers to the same underlying data, a copy is made of the data before an array element is altered.

A gather operation, or vector index operation is expressed by a[i] where i is an iarray variable. The expression a[i]=x scatters the values of x into the array a according to the vector i. Naturally, the length of i and x must agree. A fresh copy of a data is made if needed.
