Instrumentation

Currently four instrumented widgets are included in the Ecolab distribution. The first time these widgets are called, they instantiate themselves in a separate window. This follows the philosophy that initialisation should be a transparent operation. A number of these widgets depend on the BLT toolkit, so it is wise to include BLT at the compilation stage. Each widget is independent, and so multiple instruments can be operating at the same time.
