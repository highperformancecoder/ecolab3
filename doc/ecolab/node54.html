connect_stub

Syntax: 

void connect_stub(iarray& density, sparse_mat& interaction, iarray& nsp, 
                  int ncells=1)

This function implements the connect_plot(§4.3.4) widget. The row and col connections are plotted, and sorted and coloured according to connected subsets. density is only used to indicate extinctions (where density[i]==0, the row and column is coloured in wheat. Set ncells>1 and cell in order to display only a single cell, as in ecolab. These variables may be ignored if not meaningful. nsp must be set with the cellular structure used by density and interaction. see §7 For a non-cellular model, it contains just the 1 component, equal the density.size.
